# OpenLawsuit：开源智能起诉辅助平台

> 让法律维权不再困难

OpenLawsuit 是一个致力于普及法律知识、降低法律维权门槛的开源项目。通过 AI 技术与开放协作，帮助普通公民更好地理解和运用法律武器，维护自身合法权益。

本项目集成了**起诉攻略指南**与**智能起诉辅助工具**两大核心模块。

## 愿景

我们坚信，法律不应是少数人的特权，而应是每个公民都能掌握的工具。

- **赋能公民**：让更多人了解法律程序，敢于拿起法律武器
- **降低门槛**：提供清晰的指引和可复用的模板，简化法律维权过程
- **AI 驱动**：通过人工智能自动生成法律文书，智能提取案件信息
- **社区协作**：汇聚法律专业人士、热心公民的力量，共同完善内容

## 核心功能

### 起诉攻略指南

提供完整的民事起诉流程指南，从证据收集到判决执行，一步步教您如何通过法律途径维护自身权益。包含常见案由分析、法律条文引用和常见问题解答。

详细内容请参阅 [`docs/guide/LAWSUIT_GUIDE.md`](docs/guide/LAWSUIT_GUIDE.md)。

### 智能起诉辅助平台

| 功能 | 说明 |
|------|------|
| 案件管理 | 创建、编辑、管理多个诉讼案件 |
| 引导式表单 | 分步引导用户填写原被告信息、诉讼请求、事实理由、证据等 |
| AI 智能文书生成 | 基于案件信息自动生成民事起诉状、证据清单等法律文书 |
| AI 法律咨询 | 集成 LLM 提供智能法律咨询，帮助理解法律条文 |
| AI 信息提取 | 用自然语言描述案件，AI 自动提取结构化信息填充表单 |
| 语音录入 | 支持语音录入案件事实和证据描述，自动转写为文字 |
| 法律知识库 | 常用法律条文速查，覆盖诉讼时效、合同、侵权等领域 |
| 通知系统 | 文书生成完成、案件状态更新时自动通知 |
| 文书预览 | 在线预览生成的法律文书，支持 Markdown 渲染 |

### 法律文书模板

提供标准化的法律文书模板，可直接下载使用：

- [民事起诉状模板](docs/templates/民事起诉状模板.md)
- [证据清单模板](docs/templates/证据清单模板.md)

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 19, Tailwind CSS 4, shadcn/ui, Wouter |
| 后端 | Express 4, tRPC 11, Drizzle ORM |
| 数据库 | MySQL / TiDB |
| AI | LLM 集成（文书生成、法律咨询、信息提取） |
| 语音 | Whisper API（语音转文字） |
