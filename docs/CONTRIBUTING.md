# 贡献指南

感谢您对 OpenLawsuit-Guide 项目的关注和支持！我们欢迎所有对法律普及和公民维权有热情的伙伴加入，共同完善和发展这个项目。

## 如何贡献

您可以通过以下方式为本项目做出贡献：

### 1. 提交问题和建议 (Issues)

如果您在使用过程中发现任何问题、有改进建议，或者希望增加新的内容（例如某个特定类型的案件指南或法律文书模板），请随时在 GitHub Issues 中提出。在提交 Issue 时，请尽量提供详细的描述，以便我们更好地理解和解决问题。

### 2. 贡献代码和内容 (Pull Requests)

我们鼓励您通过 Pull Request (PR) 的方式直接贡献代码或内容。在提交 PR 之前，请确保您已阅读并理解以下准则：

#### 2.1 内容贡献准则

*   **准确性**：所有贡献的法律内容必须准确无误，并尽可能提供法律依据（如法律条文、司法解释、权威案例等）。
*   **实用性**：内容应以帮助普通公民理解和操作为目标，避免过于专业的法律术语，或在必要时进行解释。
*   **清晰性**：文档结构清晰，逻辑严谨，易于阅读和理解。
*   **格式**：请遵循 Markdown 格式规范，保持文档风格一致。
*   **原创性**：请确保您贡献的内容不侵犯任何第三方的知识产权。

#### 2.2 技术贡献准则

*   **代码规范**：如果您贡献的是代码（例如辅助工具），请遵循项目现有的代码风格和规范。
*   **测试**：请确保您的代码经过充分测试，并提供相应的测试用例。

#### 2.3 提交 PR 的步骤

1.  **Fork 本仓库**：点击 GitHub 页面右上角的 "Fork" 按钮，将本仓库复制到您的个人账户下。
2.  **克隆到本地**：将您 Fork 后的仓库克隆到本地计算机。
    ```bash
    git clone https://github.com/您的GitHub用户名/OpenLawsuit-Guide.git
    ```
3.  **创建新分支**：为您的贡献创建一个新的分支。请使用有意义的分支名称，例如 `feature/add-contract-template` 或 `fix/typo-in-guide`。
    ```bash
    git checkout -b your-new-branch-name
    ```
4.  **进行修改**：在您的新分支上进行内容或代码的修改。
5.  **提交更改**：提交您的更改，并编写清晰的提交信息。
    ```bash
    git commit -m "feat: add new contract template"
    ```
6.  **推送到远程仓库**：将您的本地分支推送到您的 GitHub 仓库。
    ```bash
    git push origin your-new-branch-name
    ```
7.  **创建 Pull Request**：访问您 Fork 后的 GitHub 仓库页面，您会看到一个提示，引导您创建 Pull Request。请填写详细的 PR 描述，说明您的更改内容和目的。

### 3. 传播与推广

如果您认为本项目有价值，请帮助我们传播和推广，让更多有需要的人知道并使用它。您可以通过社交媒体、博客、论坛等方式分享本项目。

## 行为准则

我们致力于营造一个开放、友好、尊重的社区环境。所有参与者都应遵守以下行为准则：

*   **尊重他人**：以尊重的态度对待所有社区成员，避免人身攻击、歧视或骚扰。
*   **开放沟通**：鼓励开放、建设性的讨论，欢迎不同的观点和意见。
*   **协作精神**：积极与他人协作，共同解决问题，提升项目质量。

任何违反行为准则的行为都可能导致被暂时或永久禁止参与本项目。

再次感谢您的贡献！
